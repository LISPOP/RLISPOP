Import the data

Let’s work with the Survey of Household Spending dataset that is stored in the course_data subfolder. Note that that folder is stored in a folder above the current working directory. If you have opened up the 05_univariate_statistics.Rproj folder then you should be in that working directory.

For me, on my computer, that directory is:

But the data set is stored in a folder next to 05_Univariate_Statistics. The here() package can help us get there.

By adding .. to here() we move up one directory, then we can add the name of the directory course_data.

library(haven)
shs<-read_sav(here('..','course_data', 'shs.sav'))

Let’s play with these two variables. Note, that in the select() command you can change the names the same way as with the rename() command.

shs %>%

Measures of Central Tendency

One of the first things you want to know with a variable is a measure of where the center is, or what the typical value of that variable is. These are variables of central tendency. There are three: mean, median and mode. All three can be used to describe numeric variables, but only mode can be used to describe categorical variables.

Mean

We find the mean of a variable with mean()

mean(shs_subset$Income)
[1] 86698.86

Note that if there are any missing values in a variable, you will need to set na.rm=T.

mean(shs_subset$Income, na.rm=T)
[1] 86698.86

You can always save the result.

mean_income<-mean(shs_subset$Income)
mean_income
[1] 86698.86

Median

The trouble with the average is that it is vulnerable to outliers. The classic joke is that if Bill Gates walks into a room with 100 people suddenly the average income of the room skyrockets. In cases like this, the better measure is the median() which finds the value at which half the values are below and half are above.

median(shs_subset$Income)
[1] 71662.5

Mode

In fact, there is no built-in command to take the mode of a variable. The way to do it is to run a table() command on a variable and count the categories that have the most responses.

table(shs_subset$Dwelling)

               Single detached Double, row, terrace or duplex 
                          7730                           1858 
            Apartment or other 
                          2904
