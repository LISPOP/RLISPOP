The syntax of ggplot()

The basic syntax of ggplot2 is universal throughtout the whole library. It looks like this:

ggplot(data=name_of_data_frame, mapping=aes(x=name_of_x_variable, y=name_of_y_variable))+geom_*

So what are we looking at here: 1. The first part is the call to ggplot(). It requires a data argument, which must be a data frame. If you pipe a dataset to it, you an replace the argument with a . So hypothetically, these are equivalent.

ggplot(data=dat, aes(x=x, y=y))
dat %>% 
  ggplot(., data=., aes(x=x, y=y))
  1. Inside the ggplot() call, it is necessary to define the mapping of the plot. This specifies which variable in the data frame is mapped to which feature of the graph. In the simplest form of a one-variable graph, like a histogram,only an x- is specified. Note, that it is possible to only specify a y- variable, for the case of a bar graph that is set horizontally.

In theory, aes() is set to a mapping argument, i.e. 

dat %>% 
  ggplot(., mapping=aes(x=x, y=y))

However, because R matches arguments by position as well, as long as you put the mapping after the data argument, you don’t need to worry about typing the mapping=. I never do this anymore. So this is fine:

dat %>% 
  ggplot(., aes(x=x, y=y))

Here, isalso where we also specify grouping (third or fourth or figth variables) mapped to the aesthetic features of a graph, such as thickness, color, fill, point shape, point size, transparency, etc.

  1. Lastly, it is necessary to add a geom to the graph, connected to the main call with a +. Note that the + functions sort of like the %>% character in the rest of the tidyverse. The difference is explained by the fact that ggplot was developed before the tidyverse.

This effectively specifies the way to represent the mappings in a geometric feature (e.g. point, shape, line, bar).

A full list of geoms is available here: .

Note they range from the standard: geom_line(), geom_point(), geom_bar() to the more surprising, e.g. geom_text() for text labels, geom_abline() for a straight vertical or horizontal line.

dat %>% 
  ggplot(., aes(x=x, y=y))+geom_point()

One Variable

Sometimes we want to visualize the distribution of one variable.

Histograms

A histogram is a classic and important graph design to visualize the distribution of values for a numeric variable. It can answer a lot of different questions such as:

  • are values of a variable clustered around an average, or are they spread out quite a bit?
  • Are there any outlier instances of a variable that are worth looking at?
ggplot(shs_subset, aes(x=Income))+geom_histogram()

We can also run the same code in some of the classic tidyverse syntax where we pipe data right to ggplot() Sometimes I do this, and sometimes I don’t; it really depends.

shs_subset%>% 
ggplot(., aes(x=Income))+geom_histogram()

We can also save plots in objects and then modify them later.

#Save in histogram1
shs_subset%>% 
ggplot(., aes(x=Income))+geom_histogram()->histogram1
#Now print. 
histogram1

We’ll see how we can use this feature in the next section.

Density Plots

Another example of a type of plot that shows the distribution of a variable is a density plot. This is a smoothed version of a histogram. In these graphs, the y-axis value is not the number of instances of a variable in a bin, but the probability that a variable takes on the value at that y-axis or less.

shs_subset%>% 
ggplot(., aes(x=Income))+geom_density()

Notice right away something useful about ggplot. We used the exactly same syntax to build the logic of the plot and then just changed the geom from a histogram to a density plot.

geom_bar() is for when you have no counts to specify the height of the bar graph’s bars. geom_col() is when you do have a column that can specify the heights of the bars.

Bar graphs of percents

Notice above that we had counts of in certain boards, but what if we want to have percent of schools in certain boards. This is an extremely common problem so it is worth focussing how to get it right here.

Recall this code gives us the number of schools in each type of board.

shs_subset %>% 
  group_by(Dwelling) %>% 
  summarize(count=n())
# A tibble: 3 × 2
  Dwelling                       count
  <fct>                          <int>
1 Single detached                 7730
2 Double, row, terrace or duplex  1858
3 Apartment or other              2904

What we need is a column to the right of the count column that is the percentage each row makes up of the total. The first go was a summarize function, but now we need to mutate those values to be percentages.

shs_subset %>% 
  group_by(Dwelling) %>% 
  summarize(count=n()) %>% 
  mutate(percent=count/sum(count))
# A tibble: 3 × 3
  Dwelling                       count percent
  <fct>                          <int>   <dbl>
1 Single detached                 7730   0.619
2 Double, row, terrace or duplex  1858   0.149
3 Apartment or other              2904   0.232

Now we have the percentages! So roughly 33% of schools in Ontario are in Catholic school boards. So what if we want to graph those.

Because we have the y-value we want to specify, we will use geom_col(). We will come to modifying the scales to report percentages later.

shs_subset %>% 
  group_by(Dwelling) %>% 
  summarize(count=n()) %>% 
  mutate(percent=count/sum(count)) %>% 
  ggplot(., aes(x=Dwelling, y=percent))+geom_col()

Boxplots

Another type of graph that is used to visualize a variable is the boxplot. This contains a lot of statistical information. 1. The thick line in the middle is the median value. So half the values are above that line and half are below. 2. The outer thin lines are thequartiles. 25\% of the values lie on either side of the thick line. Combined, the two thin lines (e.g. the box are known as theIQRor theinterquartile rangew.) 3. The thin lines from the box to the outer edges are values that stretch from the 25\% (75\%) percentile to theminimumor themaximum. 4. The dots are known asoutliers`, data points that are far away from the median.

ggplot(shs_subset, aes(x=Income))+geom_boxplot()

ggplot(shs_subset, aes(y=Province, x=Income))+geom_boxplot()

Scatterplots

Scatterplots are the most common way to visualize two numeric variables.

Here we can examine the correlation between the percent of students meeting the provincial standard for grade 9 math and the percent of students meeting the standard for literacy.

shs_subset %>% 
  ggplot(., aes(x=Income, y=Taxes))+geom_point()

The relationship between the two variables can be spelled out with a geom_smooth() which prints a line of best fit. The most basic way is to fit a straight line between the two variables.

shs_subset %>% 
  ggplot(., aes(x=Income, y=Taxes))+geom_point()+geom_smooth(method="lm")

Another method is to fit something that is more curvy; a loess line only draws the line using a few points at a time, so it allows for curves.

shs_subset %>% 
  ggplot(., aes(x=Income, y=Taxes))+geom_point()+geom_smooth(method="loess")

Aesthetics

But in addition to adding a y-variable to a lot of the graphs above we can also vary the aesthetics of a graph with one variable to show a different variable. For instance, if we go back to a density plot of Income , we can show the difference by type of dwelling of residence by specifying fill=Dwelling

ggplot(shs_subset, aes(x=Income, fill=Dwelling))+geom_density()

Note that every geom has different aesthetics can be modified. For example, histograms and bar graphs and density plots can all have their fill or their color modified.

The best way to read what can be modified is to look at the help file for each geom.

?geom_density()

So here, we see that we can modify a density plot’s x, y, alpha, color, fill, gtroup, linetype, size and weight. Play around with the different aesthetics.

ggplot(shs_subset, aes(x=Income, col=Dwelling))+geom_density()

Note also that you can combine aesthetics to vary two things at once. So we can modify the fill and the alpha at the same time. Now you get not only a different color, but a different transparency as well.

ggplot(shs_subset, aes(x=Income, fill=Dwelling, alpha=Dwelling))+geom_density()

Notice that when you map aesthetics to a variable’s values the legend is automatically updated!

We can do this with the histogram:

ggplot(shs_subset, aes(x=Income, fill=Dwelling, alpha=Dwelling))+geom_histogram()

We can also do this with bar graphs. And there are a few ways to do this. The easiest way is just to show the counts of values in each group.

Here we show the number of schools in each board type and language group:

ggplot(shs_subset, aes(x=Dwelling, fill=Tenure))+geom_bar()

However, this style of graph can be misleading, the eye is drawn to the top of the bar making it hard to grasp what proportion of the schools is in the two different groups. So we can put the bars side-by-side, like this:

ggplot(shs_subset, aes(x=Dwelling, fill=Tenure))+geom_bar(position="dodge")

Sometimes we want to just show the pure distribution within groups:

ggplot(shs_subset, aes(x=Dwelling, fill=Tenure))+geom_bar(position="fill")

note though that this shows something very specific. It shows the percentage of Dwelling types that are owned with or without a mortgage or rented.

Facets

Another way that we can add another variable is with panels or facets.

There are two types of facets: facet_wrap() and facet_grid()

This is a wrap

ggplot(shs_subset, aes(x=Income))+geom_histogram()+facet_wrap(vars(Dwelling))

And this is a grid

ggplot(shs_subset, aes(x=Income))+geom_histogram()+facet_grid(vars(Dwelling))

There are different things you can do with both. With facet_wrap you can specfiy how many rows and columns you want.

ggplot(shs_subset, aes(x=Income))+geom_histogram()+facet_wrap(vars(Dwelling), nrow=1)
ggplot(shs_subset, aes(x=Income))+geom_histogram()+facet_wrap(vars(Dwelling), nrow=2)

And in facet_grid you can specify a row and a column variable.

ggplot(shs_subset, aes(x=Income))+geom_histogram()+facet_grid(rows=vars(Dwelling), cols=vars(`Tenure`), scales='free')

Mapping Versus Setting

We often want to modify the colors of graphs for a lot of reasons, sometimes it is as simple as complying with a media company’s color palette. For example, the Toronto Star is a heavily blue branded outlet; while the Globe and Mail heavily emphasizes red.

There are key things to note when changing visual aesthetics of a graph: there is a mapping and a setting.

In the following graph, the color of the points is just set to black.

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes))+geom_point()

We might want to set the colors of these points to be something, or we might want to set the size of the points, just to better fit the medium in which we are publishing.

We can do this straightforwardly inside the geom_point()

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes))+geom_point(color="red")

The very best list of R colors available for use is here.

We might also want to set the size, or the shape of the points.

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes))+geom_point(color="red", size=5, shape=3)

You can find the list of point shapes available here.

We can also set the fill of some point shapes, but not all. There is no substitute for playing around.

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes))+geom_point(color="red", fill="blue", shape=23)

However, changing the appearance of visual aesthetics which have been mapped to a category is a different process. Here, the colors are not set, they are mapped to the categories dwelling type.

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes, col=Dwelling))+geom_point()

Suppose we want to use a different set of colors to be used for the mapping, like, let’s say, red and green.

To do so, we need to introduce a series of functions that have the same type of structure. These are:

scale_col_discrete() scale_col_continuous() scale_fill_discrete() scale_fill_continuous scale_size_discrete() scale_size_continuous

In order to make this work, we need to know what type of aesthetic we need to modify (e.g. the color, the fill, the size, the shape) and what type of variable is the mapping variable.

In this case, we have mapped the colors to a discrete variable, which is another name for categorical variables. So we use scale_color_discrete

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes, col=Dwelling))+geom_point()+scale_color_discrete(type=c("darkgreen", "gold", "lightgreen"))

Note that you can also reverse the colors to specifically link a color to level

shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes, col=Dwelling))+geom_point()+geom_point()+scale_color_discrete(type=c("lightgreen", "gold" , "darkgreen"))

Some scales can be mapped to numeric or continuous variables, while other can only be mapped to continuous variables.

Picking Palettes

There are also a series of R packges that let us pick pre-built palettes of colors. One of the best is the RColorbrewer package

When we are mapping a color palette to a categorical variable, like we are here with Dwelling, and we provide the type argument (either seq, qualitative, or diverging) and then pick the palette.

#install if necessary
#install.packages('RColorBrewer')
library(RColorBrewer)
shs_subset %>% 
ggplot(., aes(x=Income, y=Taxes, col=Dwelling))+geom_point()+scale_color_brewer(type="seq", palette="Greens")

Factor Orders

Often we want to change the order of categories for categorical variables in order to communicate some information. Here is the graph that shows the average income by province.

average_incomes %>% 
ggplot(., aes(y=Province, x=Average_Income))+geom_col()

It would be nice to order the names of the provinces so that the ones with the highest incomes are at the top. Here we use a powerful tidyverse package called forcats. It provides the fct_relevel() function which changes the order of the levels of its main argument by the values in its second argument.

average_incomes %>% 
  #fct_reorder reorders the levels ofthe factor variable by the values of the second numeric variable
  ggplot(., aes(y=fct_reorder(Province, Average_Income), x=Average_Income))+geom_col()

We can reverse the orders like this, by adding .desc=T.

average_incomes %>% 
  #fct_reorder reorders the levels ofthe factor variable by the values of the second numeric variable
  ggplot(., aes(y=fct_reorder(Province, Average_Income), x=Average_Income, .desc=T))+geom_col()

Axis and Graph Labels

Notice now however that the y-axis labels are kind of ….not very nice. The labs() layer is very easy to modify.

average_incomes %>% 
  #fct_reorder reorders the levels ofthe factor variable by the values of the second numeric variable
  ggplot(., aes(y=fct_reorder(Province, Average_Income), x=Average_Income))+geom_col()+labs(x="Average Household Income", y="Province", title="Average Total Household Income By Province")

We can also wrap a long title onto two lines using the str_wrap() function which comes from the stringr library

average_incomes %>% 
  #fct_reorder reorders the levels ofthe factor variable by the values of the second numeric variable
  ggplot(., aes(y=fct_reorder(Province, Average_Income), x=Average_Income))+geom_col()+labs(x="Average Household Income", y="Province", title=str_wrap("Average Total Household Income By Province", 30))

We can also modify the size of the text on the axes.

Here we need to understand the theme() layer. theme() can accept arguments at a very high level of generality, right down to extremely specific.

So, for example, we can change the font family, the size and the color of all the text in the graph.

Customizing Themes

You can modify all these parts graph by graph, or you can go further and actually customize your theme.

Let’s start by storing the regular theme

theme_mine<-function() {
  theme(
  panel.background=element_rect(fill="darkred")
)}

Let’s check to see if that works:

average_incomes %>% 
  #fct_reorder reorders the levels ofthe factor variable by the values of the second numeric variable
  ggplot(., aes(y=fct_reorder(Province, Average_Income), x=Average_Income))+geom_col()+labs(x="Average Household Income", y="Province", title="Average Total Household Income By Province")+theme_mine()

Let’s pick a font family:

theme_mine<-function() {
  theme(
    text=element_text(family="mono"),
  panel.background=element_blank(),
  panel.ontop = T,
  panel.grid.major.x = element_line(color="lightgray", linetype=2),
  plot.title=element_text(color="darkgreen")
  )
}

And let’s redraw the plot again:
